# Python Chess

A chess game built with Python and Pygame.

The project includes Player vs Player and Player vs AI modes, multiple AI difficulty levels, move history, captured pieces, board flipping, pawn promotion, and standard chess rules such as castling, en passant, checkmate, stalemate, and repetition draws.

## Features

- Player vs Player
- Player vs AI
- Easy, Medium, and Hard AI difficulties
- Negamax search with alpha-beta pruning
- Quiescence search
- Transposition table
- Move ordering and opening heuristics
- Castling
- En passant
- Pawn promotion
- Threefold repetition detection
- Insufficient material detection
- Undo and restart
- Move history
- Captured pieces display
- Automatic board flipping when playing Black

## Controls

- Mouse - select and move pieces
- `Z` - undo
- `Esc` - restart the game
